AI 增強工具箱

目前讓 Claude（以及類似 AI 助手）變得更好用的資源，大致分成三層：Skill（教 AI 一套做事方法）、MCP 伺服器（讓 AI 接上外部工具和資料）、內建習慣（不用裝任何東西，改變使用方式就有效）。下面每一項都標了推薦程度，挑你有興趣的跟我說，我就幫你裝到這個 repo，之後每個 session 都會自動生效。

三層概念SkillMCP內建習慣建議起手式

先搞懂三層

第 1 層Skill一個資料夾裡放 SKILL.md，寫著「遇到某類工作時要怎麼做」。AI 只有在需要時才載入，不會佔記憶。例：寫測試的流程、除錯步驟、設計規範
第 2 層MCP 伺服器讓 AI 多一組工具，可以讀寫 GitHub、查最新文件、操作瀏覽器、查資料庫。例：GitHub、Context7、Playwright
第 3 層內建習慣Claude Code 本身就有的功能：專案說明檔、規劃模式、Hook、子代理。零安裝、效果最直接。例：CLAUDE.md、Plan mode

Plugin（外掛）則是把 Skill、MCP、指令打包在一起的安裝包，用 /plugin 指令從 marketplace 安裝。

熱門 Skill 資源

anthropics/skills（官方）

最推薦

Anthropic 官方的 Skill 範例庫。包含 Word / Excel / PowerPoint / PDF 文件處理、前端設計 (frontend-design)、建立新 Skill 的 skill-creator 等。最可靠的起點。

注意：文件類 skill 是 source-available，僅供參考，其他多為 Apache 2.0

obra/superpowers

最推薦

社群最常被推薦的一套。20 多個實戰流程：先寫測試再寫程式 (TDD)、系統化除錯、先規劃再執行、程式碼審查。適合寫程式的 session，能明顯減少 AI 亂改或跳步驟。

frontend-design

做網頁時

讓 AI 做出來的介面不再是千篇一律的「AI 感」設計。安裝數非常高，做任何前端畫面都值得開。

travisvn/awesome-claude-skills

目錄

整理最完整、被引用最多的 Skill 清單。想找特定領域（行銷、資料分析、安全）的 skill 時，從這裡翻。

ComposioHQ/awesome-claude-skills

目錄

另一份大型精選清單，偏重和外部 App 串接的 skill。

Karpathy 風格行為規則

寫程式時

把 Andrej Karpathy 歸納的「LLM 寫程式常犯錯誤」寫成規則，例如不要過度設計、不要亂改沒被要求的地方。很適合直接放進 CLAUDE.md。

Trail of Bits 安全 skills、Addy Osmani agent-skills / web-quality-skills

進階

專業團隊出的領域 skill：資安審查、網頁效能與品質檢查。有對應需求再裝。

各篇文章列的 GitHub 星數差很多，排名只能當參考。第三方 skill 可能附帶會執行的腳本，安裝前我會先幫你讀過內容。

常用 MCP 伺服器

GitHub MCP

你已經有

幾乎每份清單都排第一：讀寫 issue、PR、Actions、release。這個 session 環境已經內建。

Context7

最推薦

讓 AI 查到函式庫的最新官方文件，避免它用過時的 API 寫程式。寫程式時效果很明顯。

Playwright MCP

做網頁時

讓 AI 開瀏覽器實際點擊、截圖、測試你的網頁。安裝：claude mcp add playwright npx @playwright/mcp@latest

搜尋 / 爬蟲：Firecrawl、Tavily、Exa、Brave Search

選用

需要大量讀網頁、做研究時補強。內建的搜尋已能應付一般需求。

資料庫、Slack、Linear、Notion 等

看需求

依你用的服務接。MCP 裝太多會佔 AI 的注意力，原則是用得到才裝。

不用安裝的內建習慣

CLAUDE.md 專案說明檔

最推薦

放在 repo 根目錄，每個 session 開始時 AI 自動讀取。寫上：專案在做什麼、怎麼測試、你的偏好（例如「回覆用繁體中文」「改動前先說明計畫」）。這是讓「每個 session 都一樣聰明」最直接的方法。可用 /init 自動產生初稿。

Plan mode（規劃模式）

大改動前

按 Shift+Tab 切換。AI 先列出計畫給你確認，不會直接動手改檔案。

專案內的 Skill 資料夾 .claude/skills/

可共用

把 skill 放進 repo 的這個資料夾並 commit，之後任何 session 開這個 repo 都能用。

Hooks

進階

在特定時機自動執行指令，例如每次改完檔案自動跑格式化、session 開始時自動安裝套件。

Subagents（子代理）與 /code-review

進階

把大型搜尋或審查交給另一個代理，主對話保持乾淨；內建的 /code-review、/security-review 可直接檢查你的改動。

建議起手式

  1. 建立 CLAUDE.md：寫入你的語言偏好和工作規則（含 Karpathy 式行為規則）。
  2. 把 superpowers 的核心流程（TDD、除錯、規劃）放進 .claude/skills/。
  3. 加入 Context7，讓 AI 寫程式時查最新文件。
  4. 做網頁時再加 frontend-design 和 Playwright。
