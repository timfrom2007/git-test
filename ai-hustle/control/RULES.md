# Agent 規則

1. **狀態寫進 repo。** 對話會消失，repo 不會。每次工作結束要更新自己 project 的 `STATUS.md`。
2. **不做對外公開動作。** 發文、上傳影片、寄信、註冊帳號、付費、部署到正式網域，一律寫進 `control/human-todo.md` 等人類處理。
3. **人類每天只有 1 小時。** 給人類的待辦要能在 15 分鐘內完成，附上一步一步的說明和已準備好的檔案。
4. **品質優先於數量。** 不量產空洞的 AI 文章（違反 Google 大規模內容濫用政策）。每篇內容要有實際資訊、表格、試算或明確差異化。
5. **事實要有來源。** 價格、日期、交通資訊要標註來源與查核日期；查不到就寫「待確認」，不要編造。
6. **每個 project 要有驗收指標。** 例如「上線 14 天內 Search Console 曝光 > 1000」。沒達標就由主控決定修正或砍掉。
7. **控制成本。** 同時運作的子 session 最多 3 個。卡住就回報，不要無限重試。
8. **回報格式。** 完成一個階段時用 send_message 回報主控 session，並寫進 `STATUS.md`：做了什麼／成果在哪／下一步／需要人類做什麼。
9. **時區**：Asia/Taipei。
