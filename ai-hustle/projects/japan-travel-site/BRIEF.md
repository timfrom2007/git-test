# Project A：日本旅遊工具站

## 目標
以「互動工具為主、懶人包文章為輔」取得台灣（繁中）搜尋流量，透過聯盟行銷（Klook、KKday、Agoda/Booking、網卡/eSIM）變現。

## 差異化
- 工具頁：JR Pass／地區周遊券划算試算、旅遊預算計算機、退稅試算
- 時效內容：2027 櫻花／楓葉預測、祭典日曆
- 冷門長尾行程：四國、北陸、山陰等

## 技術
- 靜態網站（建議 Astro），部署 Vercel（人類已有 Vercel 帳號經驗）
- 程式碼放在本 repo 的 `ai-hustle/projects/japan-travel-site/site/`
- SEO 基本功：sitemap、結構化資料、OG 圖、Core Web Vitals

## 第一階段交付（A1）
1. 網站骨架可在本地 build
2. 第一個工具：JR Pass／周遊券划算試算（票價資料標註來源與查核日期）
3. 3 篇支援文章
4. 給人類的部署與 Search Console 設定步驟

## 驗收指標
上線 30 天內 Search Console 曝光 > 1,000、點擊 > 50。
