# 帳號定位建議

## 一句話定位
**「出發去日本前，60 秒搞懂新規則、日期和怎麼省錢。」**
不露臉、資訊密度高、每支都附來源；網站負責「算給你看」，短影音負責「告訴你有這件事」。

## 名稱候選
| # | 名稱 | 優點 | 缺點 |
|---|---|---|---|
| 1 | **日本行前60秒**（推薦） | 直接說出價值（出發前、很短）；跟影片長度一致；可延伸「行前60秒｜韓國」 | 「60秒」限制長片延伸 |
| 2 | 日本旅遊新制快報 | 搜尋友善（含「日本旅遊」） | 新制題材用完就沒新意，季節題不貼切 |
| 3 | 日本省錢研究室 | 跟網站試算工具最契合 | 「省錢」帳號很多，辨識度低 |
| 4 | 去日本前先看 | 口語、好記 | 太長、品牌感弱 |
| 5 | 一分鐘日本 | 短 | 太泛，可能已被註冊 |

**建議**：用 #1，並且**跟 Project A 網站用同一個品牌名**（或至少在網站 header 放「日本行前60秒」字樣），觀眾從影片點過去才不會覺得跑錯地方。這需要主控和 Project A 協調（已在回報中提出）。

Handle 建議：`@japan60s`、`@japan.before60`、`@xingqian60`（按順序試，人類註冊時確認是否可用）。

## 風格
| 項目 | 規範 |
|---|---|
| 語氣 | 像懂很多的朋友在提醒你：短句、口語、不誇大。不用「震驚」「必看」之類的標題黨用詞（封面可以有「必看」，旁白不要） |
| 視覺 | 深色漸層背景＋白色大字＋單一強調色（每支影片換主題色）；字卡放畫面上方 1/4 到 2/3，避開平台按鈕 |
| 聲音 | 首選人類自己錄（台灣口音，可信度高，手機錄音即可）；次選 AI 旁白（見 `tools/README.md` 的限制） |
| 字幕 | 一律燒入字幕（台灣觀眾常靜音滑） |
| 長度 | 35–50 秒，每支 3–4 個重點 |
| 結尾 | 固定一句：「主頁連結有 ○○。追蹤我，出發前 60 秒搞懂日本新制。」 |
| 可信度 | 說明欄一定附「資料來源＋查核日期」。這是跟一般旅遊帳號的差異，也符合 RULES 第 5 條 |

## 與網站（Project A）的關係
```
短影音（發現）  ──→  主頁連結（Linktree 或網站首頁）  ──→  網站工具／懶人包（試算、聯盟連結變現）
 「有這件事」              一個連結                       「算給你看、幫你訂」
```
- 每支影片對應網站上一個**具體頁面**（見各 `videos/NN/README.md` 的「導流」欄）。網站頁面未上線時，先導到首頁或相關懶人包。
- 主頁連結建議直接放網站首頁，首頁放「最新影片提到的工具」區塊（Project A 可以做）。
- 網站文章底部嵌入對應 Shorts，互相加權。
- Shorts 本身不放聯盟連結（YouTube Shorts 說明欄連結不可點），變現在網站端完成。

## 平台優先順序
1. **YouTube Shorts**：可被搜尋、長尾流量，最符合「資訊型」內容
2. **IG Reels**：台灣滲透率高；同一支影片上傳即可
3. **Threads**：同時發一則文字版（3 個重點＋影片），討論型內容在 Threads 擴散快

## 驗收指標（沿用 BRIEF）
發布 14 天內，單支最高觀看 > 5,000，或總追蹤 > 200。
追加觀察指標：平均觀看比例 > 70%（低於 50% 就改 hook）、主頁連結點擊數（UTM 依 Project A 的 `LINKS.md`：`?utm_source=youtube|instagram|threads&utm_medium=shorts&utm_campaign=vNN`）。
