# 錄音指南（約 10 分鐘，含上傳）

目的：錄一段 1–3 分鐘的聲音樣本，讓 AI 學你的聲音和台灣腔，之後每支影片都能自動用「你的聲音」產出旁白，不用每支都錄。

## 事前（2 分鐘）
1. **不要把聲音樣本放進 `timfrom2007/git-test`**：這個 repo 是**公開的**，而且是 `udemy-course/git-test` 的 fork，GitHub 不允許把公開 fork 改成私有（2026-11-22 查核）。聲音樣本可以被拿去複製你的聲音，所以要放在**另一個私有 repo**：
   - GitHub 右上「＋」→「New repository」→ 名稱 `ai-hustle-voice` → 選 **Private** → 勾「Add a README file」→ Create。
2. 找一個**安靜、有窗簾或衣櫃的小房間**（布料會吸回音；浴室、空曠客廳回音太大）。
3. 關掉冷氣、電扇、電視；手機開飛航模式（避免通知聲）。

## 錄音（5 分鐘）
1. iPhone 打開「語音備忘錄」（Android 用「錄音機」）。
   - iPhone 設定 →「語音備忘錄」→ 音訊品質選「無損」（沒有這個選項就略過）。
2. 手機放在嘴巴前方約 **20 公分**（一個手掌張開的距離），不要正對嘴巴，稍微偏一點避免噴麥。
3. 打開 `voice/script.txt`，從「[0 同意聲明]」開始照念到最後。
   - 用**平常講話**的速度和語氣，像在跟朋友介紹，不要刻意播報腔。
   - 念錯：停 1 秒，從那一句重念就好，AI 處理時會剪掉。
   - 每段之間停 1 秒。
4. 念完後聽前 10 秒：有沒有雜音、聲音會不會太小或破音。有問題就重錄。

## 上傳（3 分鐘）
1. 把檔案名稱改成 `sample.m4a`。
2. 瀏覽器打開剛建立的私有 repo `ai-hustle-voice` →「Add file」→「Upload files」→ 拖進 `sample.m4a` → Commit changes。
3. 在 `projects/short-video/STATUS.md`「人類決定」寫一行：`聲音樣本已上傳到 ai-hustle-voice，YYYY-MM-DD`。
4. 告訴主控（或在 Claude 對話裡說一聲），AI 會把這個私有 repo 加進 session 讀取，**不會把音檔複製回公開 repo**。

## 常見問題
- **一定要 3 分鐘嗎？** 不用。照稿念完大約 2 分鐘就夠；零樣本模型只會用其中 10–30 秒當參考，其他用來挑最乾淨的片段。
- **可以用 AirPods 錄嗎？** 不建議，藍牙麥克風音質較差。直接用手機本體麥克風。
- **之後還要錄嗎？** 不用。除非想換語氣，或 AI 產出的品質不好。
- **我不想讓 AI 複製我的聲音？** 那就不要上傳；改選 Azure 台灣腔 AI 語音（不是你的聲音，見 `voice/README.md`）。
